# deltahive

Delta and reshape hive text streams with deterministic transforms.

**Site:** https://theworker02.github.io/deltahive/

## Install / run

```bash
git clone https://github.com/theworker02/deltahive.git
cd deltahive
node src/cli.js
node --test
```
